# 1000xscripts

This directory contains operational PowerShell scripts for managing the GigaSwap project environment, specifically focused on synchronizing rules and maintaining the script environment.

## Available Scripts

*   **`Sync-All.bat`**: 
    *   Wrapper script that invokes `Sync-CursorRules.ps1`.
    *   Purpose: Synchronizes rule definitions from `1000xrules/` to `.cursor/rules/`.
    *   Options: `-DetectOrphans`, `-RemoveOrphans`.

*   **`Sync-CursorRules.ps1`**: 
    *   The core synchronization logic called by `Sync-All.bat`.
    *   Reads `.md` files from `1000xrules/` (excluding `README.md`).
    *   Creates/Updates corresponding `.mdc` files in `.cursor/rules/`, preserving existing frontmatter.
    *   Relies on functions within `rules-scripts/CursorRules.psm1`.
    *   Generates reports in `sync-reports/`.

*   **`Clean-SyncReports.ps1`**: 
    *   Utility script to clean up old synchronization reports.
    *   Keeps a specified number of the most recent reports (default: 5) in `sync-reports/`.

*   **`rules-scripts/CursorRules.psm1`**: 
    *   PowerShell module containing helper functions used by `Sync-CursorRules.ps1` (e.g., for handling frontmatter and content extraction).

## Directory Structure

*   **`sync-reports/`**: Stores timestamped reports generated by `Sync-CursorRules.ps1`.
*   **`rules-scripts/`**: Contains the `CursorRules.psm1` module required by the sync script.

## Usage

### Synchronize Rules (`1000xrules` -> `.cursor/rules`)

```powershell
# Navigate to the scripts directory
cd 1000xscripts

# Run basic sync (updates/creates rules)
.\Sync-All.bat

# Run sync and detect orphans (but don't remove)
.\Sync-All.bat -DetectOrphans

# Run sync and remove orphans
.\Sync-All.bat -RemoveOrphans
```

### Clean Old Sync Reports

```powershell
# Navigate to the scripts directory
cd 1000xscripts

# Run cleanup (keeps the 5 most recent reports)
.\Clean-SyncReports.ps1

# Run cleanup (keeps the 10 most recent reports)
.\Clean-SyncReports.ps1 -KeepCount 10
```

## Important Notes

*   The synchronization process preserves frontmatter in existing `.mdc` files.
*   `README.md` files within `1000xrules/` are explicitly **not** synchronized.
*   Always review sync reports, especially when using `-RemoveOrphans`.
