# Utility Scripts

This directory contains general utility scripts for common tasks in the 1000xbrain cognitive architecture maintenance process.

## Available Scripts

### Specialized File Handling

- **Clean-Backups.ps1** - Utility to remove backup files from the .cursor/rules directory
  - Finds and removes .mdc.bak, .bak, and other backup files
  - Provides clear reporting of deleted files
  - Supports WhatIf mode for safe preview

- **Generate-FileTemplate.ps1** - Creates new files with proper structure and frontmatter
  - Automatically creates frontmatter based on file location
  - Sets up the proper markdown structure
  - Ensures consistency with established patterns

### Usage Examples

```powershell
# Backup File Cleanup
.\Clean-Backups.ps1 -WhatIf  # Preview what would be deleted
.\Clean-Backups.ps1          # Actually delete backup files

# File Generation
.\Generate-FileTemplate.ps1 -Directory "core/identity" -FileName "new-component.md" -Title "New Component" -Description "Component description"
```

## Integration with Master Scripts

The utility scripts are integrated with the master synchronization scripts in the root directory:

- **Fix-PathMatchingAndSync.ps1** calls Clean-Backups.ps1 as part of its comprehensive workflow
- These scripts can also be used independently for more targeted operations

## Recommended Workflow

1. Use specialized scripts for targeted operations
2. Combine with maintenance scripts for comprehensive cognitive architecture maintenance
3. Always run with -DryRun or -WhatIf first to preview changes
4. Review reports generated by the scripts before making actual changes

## Additional Notes

1. All scripts include detailed help documentation accessible via Get-Help
2. Scripts generate detailed reports in the /sync-reports directory
3. All operations can be previewed in safe mode before execution

## Backup Management

The `Clean-Backups.ps1` script helps manage backup files:

- Finds all .mdc.backup* files in the .cursor/rules directory
- Removes these backup files to keep the directory clean
- Provides a preview mode to see what would be removed

### Usage

```powershell
# Preview which backup files would be removed
.\Clean-Backups.ps1 -WhatIf

# Remove all backup files
.\Clean-Backups.ps1
```

## File Templates

The `Generate-FileTemplate.ps1` script creates template files for new components:

- Provides a consistent structure for new files
- Includes properly formatted frontmatter
- Creates directories if they don't exist

### Usage

```powershell
# Create a new component
.\Generate-FileTemplate.ps1 -Directory "core/identity" -FileName "new-component.md" -Title "New Component" -Description "Description of the new component"
```

## Available Scripts

- `Convert-MdToMdc.ps1` - Converts markdown files to Cursor Project Rules format
- `Convert-MdcToMd.ps1` - Converts Cursor Project Rules to markdown files
- `Format-Markdown.ps1` - Formats markdown files according to project standards
- `Search-Architecture.ps1` - Advanced search tool for finding content across the architecture

## Usage Examples

```powershell
# Convert a markdown file to Cursor Project Rule format
.\Convert-MdToMdc.ps1 -InputFile "path/to/file.md" -OutputFile "path/to/file.mdc"

# Format markdown files
.\Format-Markdown.ps1 -Directory "workflows"
```

## Utility Categories

These utilities are organized into several categories:

- **Conversion Utilities**: Tools for converting between formats
- **Template Generators**: Tools for creating standardized files
- **Formatting Utilities**: Tools for ensuring consistent formatting
- **Search Utilities**: Tools for finding content across the architecture
- **Automation Helpers**: Helper functions used by other scripts

## Common Parameters

Most utility scripts support common parameters:

- `-Directory`: Target directory for the operation
- `-File`: Target file for the operation
- `-Recursive`: Process subdirectories recursively
- `-OutputPath`: Path for output files
- `-Verbose`: Enable verbose logging
