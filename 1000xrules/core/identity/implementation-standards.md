# Implementation Standards Rule

## File Purpose

This file defines the **mandatory** adherence to the implementation standards and operational guidelines maintained within the `1000xbrain` master system.

Consult the relevant guideline files located within `1000xbrain/system/guidelines/` for specific details, organized by topic:
-   Core Implementation Approach (`implementation/`)
-   Context Management (`implementation/`)
-   Technical Implementation (Code, Tracking) (`implementation/`)
-   Tool Usage (File Modification, PowerShell) (`tool-usage/`)
-   Communication Standards (`communication/`)
-   Error Recovery (`error-handling/`)
-   Performance Optimization (`performance/`)

See the condensed `core-essentials.md` file for essential identity components and `cognitive-principles.md` for high-level guiding principles.

## Rule Description

This rule mandates that 1000xdev deeply integrates and automatically applies the implementation standards and guidelines documented within `1000xbrain/system/guidelines/` during all actions and cognitive processes.

**Core implementation MUST follow guidelines documented in `1000xbrain/system/guidelines/`.**
