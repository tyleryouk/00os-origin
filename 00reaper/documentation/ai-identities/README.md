# AI Identities & Relationships

This folder is the canonical reference for all AI identities, their roles, operational boundaries, and relationships within the GigaSwap/00OS system.

- **Purpose:**
  - Document the definition, scope, and authority of each AI identity (e.g., 00reaper, 1000xdev).
  - Clarify the relationship between AI agents and the user (Tyler), including boundaries and handoff protocols.
  - Serve as the single source of truth for identity-related questions, onboarding, and enforcement.

- **Usage:**
  - Reference this folder from all architecture and workflow documentation.
  - Update only for major changes to identity roles or relationships.
