# 00OS Architecture Documentation

This folder contains all core documentation for the 00OS system, including the dual-mode interface, command system, and AI identity map. It is the primary reference for understanding the architecture, design, and operational principles of 00OS and its AI-driven workflows.

## Contents
- **00OS-command-user-guide.md**: End-user guide for 00OS commands and usage.
- **00OS-command-development.md**: Developer guide for creating and managing 00OS commands.
- **ai-identity-map.md**: Overview of all AI identities, their roles, and operational boundaries.
- **cursor-rules-manipulation.md**: Details the workflow for developing and syncing 00OS components using Cursor Rules.
- **command-standards-core.md**: Defines the standards for implementing 00OS commands.
- **tool-call-patterns.md**: Reference for standard tool call patterns in 00OS processes.
- **dual-mode-interface.md**: Explains the dual-mode interface (command vs. conversation) and its rationale.
