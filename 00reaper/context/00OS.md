# 00OS System Context (Current State)

This file provides a detailed snapshot of the current state of the 00OS system, including its architecture, core components, system processes, and configuration. For standards and templates, see the documentation folder.

---

## Architecture & Core Components
- **Integration:** See `core.md` for 00OS system integration details.
- **Command Handler:** Responsible for parsing and routing all terminal commands. See `00OS/core/command-handler.md`.
- **Command Registry:** Central catalog of all available commands. See `00OS/core/command-registry.md`.
- **Executor:** Loads and executes processes. See `00OS/core/executor.md`.
- **Parser:** Interprets user input as commands. See `00OS/core/parser.md`.
- **Permissions:** Manages access control. See `00OS/core/permissions.md`.
- **Registry:** Maintains process catalog. See `00OS/core/registry.md`.
- **State Manager:** Manages persistent state. See `00OS/core/state-manager.md`.

---

## Key Principles
- All 00OS processes follow the 3-step pattern (command, fetch_rules, tool calls).
- 00OS is the source of truth for process logic, system rules, and agent workflows.
- All changes are managed by 00reaper; user provides requirements and review only.
