# Major Changes Brain System

This directory contains knowledge, processes, and operational feedback for the Major Changes workflow.

## Directory Structure

- `operational_feedback/` - Contains state tracking and logs for major change cycles
- `knowledge/` - Contains knowledge files specific to major changes implementation
- `processes/` - Contains process definitions for major changes workflow steps

## Purpose

This brain subsystem provides cognitive support for the Major Changes workflow, which handles explicit change requests from Tyler Youk. It maintains:

1. **State Information** - Tracking active change cycles and their progress
2. **Process Definitions** - Structured steps for implementing each phase of the workflow
3. **Knowledge Resources** - Specialized understanding of major change implementation patterns
4. **Operational Logs** - Records of activities and decisions during change cycles

## Integration

This subsystem works closely with the command files in `1000xcommands/system/major-changes/` and leverages existing knowledge and processes from other brain subsystems where appropriate.
