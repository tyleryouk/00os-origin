## Key Architecture Concepts

- **Cognitive Architecture**: The structured knowledge system that forms 1000xdev's "mind"
- **Brain-Files**: Pure markdown files (.md) in the 1000xbrain directory
- **Cursor-Rules**: Applied rules (.mdc) in the .cursor/rules directory
- **Cognitive Enhancement**: The process of improving brain-files to enhance AI capabilities
- **Neural Pattern Optimization**: Optimizing cognitive patterns in brain-files
- **Brain-File to Cursor-Rule Relationship**: The connection between source files and applied rules
